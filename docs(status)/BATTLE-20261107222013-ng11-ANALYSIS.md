## 7. 副指挥官附注：审讯结论、已观测与推断的分界

「缺口与风险 (0)」是机械口径。以下是本轮审讯的实质结论与仍未结案的边界。

### 7.1 审讯一（重复造轮子）——成立，已修

- **已观测**：收敛前两套实现已经**语义分叉**，不是单纯重复：Forge 版的回滚句柄在改写成员集合之前
  就持有可变列表（半程失败可回滚），Fabric 版要等字段阶段与方法阶段都成功后才建句柄，`catch` 分支里
  `rollback(EMPTY)` 是空操作。新增用例 `ClassInfoMemberSyncTest#halfWayFailureRollsBackWhatWasAlreadyAdded`
  就是这条分叉的判定力：它在旧 Fabric 实现下会留下已补入的字段。
- **已修**：算法本体移到 `core` `remold.reflect.ClassInfoMemberSync`；`plugin-mixin` / `plugin-forge`
  两侧只剩类型擦除 + 日志前缀（66~70 行）。两侧共用同一失败语义与同一回滚实现。
- **降级风险（审讯一的第二点）已被探针正面覆盖**：NeoForge 判定器不仅检查「没有 warn」，还要求
  **正向同步行**（`Mixin class-info sync: ... addedFields=N, addedMethods=M`）与业务终局；6 个合成 fixture
  里专门有 `degraded.txt`、`manual-registration.txt` 两个**违规样本**，判定器必须把它们判成非 GREEN。

### 7.2 审讯二（NeoForge 共用路径）——部分成立，已按代际拆开

- **成立的部分（已观测，产物级）**：NeoForge 21.1 与 Forge 1.21.1 只共用 ModLauncher 这一层；Mixin 供应商
  不同（sponge-mixin 0.16.4+mixin.0.8.7 vs 上游），所以「同一代码路径」不能免证。真机结果：NeoForge
  21.1.265 dev `runServer` 上红基线失败形态与 Forge/Fabric **完全一致**
  （`Conform error ... ClassInfo$Method.isUnique() ... "method" is null`），说明 `reloadMixin` 复用旧
  `ClassInfo` 的行为在 sponge-mixin 上也成立；修复后两阶段 `reload=success` 且业务断言全 PASS。
- **原生注册路径成立（已观测）**：`[[mixins]]` 由 FML `ModFileParser.getMixinsConfigs` 读取并在启动早期注册；
  探针证据头 `mixin_registration=neoForge-native`，全程无 `MixinEnvironment::addConfiguration`。
- **代际断裂（已观测，产物级）**：NeoForge 26.1.2.126 库清单 `cpw.mods:*` 为 0、入口
  `net.neoforged.fml.startup.Client`、FML loader 11.0.15。现有桥接逻辑**未适配、未验证**该代际，已登记候选。
- **JPMS（已观测 + 仍属推断的边界）**：NeoForge 21.1 dev 运行全程无 `InaccessibleObjectException`，
  `add_opens=0` 完成深反射——可观测到 sponge-mixin 出现在 legacy classpath 而非 `-p` 模块路径。但
  sponge-mixin 的 `module-info` 确实只把 `transformer` 包 opens 给 gson；「dev 运行时它是未命名模块」目前
  是**推断**，要升级为观测还差一条 `ClassInfo.class.getModule().isNamed()` 诊断。**生产 installer 启动
  （`unix_args.txt`）与 NeoForge 26.x 必须重测**，不能从 dev 结果外推；产品侧已加精确 `--add-opens` 诊断。

### 7.3 本轮新增的未结案项（已进候选清单）

1. **NeoForge 26.x / FML 10 代际适配**（无 ModLauncher）：需新的织入器定位与模块层假设。
2. **NeoForge 生产 installer 启动路径验证**：模块归属可能与 dev 不同，`--add-opens` 需求需重测。
3. **Fabric 真机 E2E 本轮未重跑**：SSOT 收敛后 Fabric 侧只由`ClassInfoMemberSyncTest`（引擎）+ 
   `MixinClassInfoSyncTest`（适配器降级）覆盖，Forge/NeoForge 侧才有真机回归。若要把「无回归」提到
   与上一轮 Forge 同等级，需要重跑 Fabric 探针（`tests/fabric-mixin-probe/`，Loom 缓存已在本机）。
