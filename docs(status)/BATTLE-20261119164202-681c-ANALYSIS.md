## 5.1 已接受局限 / 挂账债务 (3)
- `recordReinitApplied` 在生产代码里仍无写入点：`hasAppliedWrite` 因此恒为 false，实际效果是"欠债且非回退上下文 → 一律 fail-closed"。这是当前正确的保守行为，但接入正常重放成功路径时，必须同时写 `written` 记录，否则闭环永远不会发生（会一直要求 OVERWRITE）。
- 字段删除的债务出账只按 `(loader, 本类内部名, 字段)` 释放；继承字段的债务键是声明类，依赖声明类自己被热更时才出账。若声明类不再加载/不再热更，该债务会留到 scope 卸载——比泄漏好，但不是即时出账。
- `RemovedFieldDebtTest` 走的是内存 loader + 离线 `ClassDiffUtil.diff`，没有真实 redefine；H1 系列已由 `vcsA14Probe` 覆盖真机路径，但本批的两条判据没有对应的 JBR 探针。
