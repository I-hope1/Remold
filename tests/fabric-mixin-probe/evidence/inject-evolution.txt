## Method

Every stage is a real `./gradlew --offline processResources compileJava` that changes only the Mixin
class source, followed by the real file watcher → `MixinHotSwap.reload` → `MixinReWeaver` re-weave →
`RemoldAgent.redefineDynamic` (JBR structural redefine of the target class). The probe asserts on
business end states: the target method's actual return value, per-invocation handler output counts,
and the class bytes actually handed to `redefineClasses` (`RemoldAgent.bytecodeCache`).
